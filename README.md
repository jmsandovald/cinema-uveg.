# Cinema UVEG

Aplicación web desarrollada en Angular para el consumo de la API de TMDB.

## Proceso de Preparación y Empaquetado

1. Se utilizó `ng build` para organizar los archivos en carpetas correspondientes (/css, /js, /assets).

2. El framework minificó los archivos CSS/JS y optimizó las imágenes de forma automática.

3. Se generó un archivo .zip listo para el despliegue final en un servidor web Apache (RHEL 8).
